# CS Curriculum / Semester Hub

An interactive, retro-inspired web portal for exploring Computer Science concepts, algorithms, and mathematical visualizers. 

This project organizes various interactive learning tools by academic semester. It acts as a centralized dashboard where users can launch different algorithmic simulators and mathematical solvers, all unified by a vintage CRT terminal aesthetic.

## 🎨 Design
The entire project shares a cohesive "hacker terminal" visual identity:
*   **Visuals:** Dark background with amber phosphor text, scanline overlays, grain, and a vignette effect to mimic an old CRT monitor.
*   **Typography:** Monospace fonts for UI elements and serif fonts for mathematical variables.
*   **UI/UX:** Single-screen layouts, glowing interactive elements, and detailed step-by-step visual feedback.

## ✨ Key Features
*   **Semester Dashboard:** A hub that organizes tools by academic semester.
*   **Interactive Visualizers:** Includes tools like a graph-based pathfinding algorithm simulator, a symbolic calculus graphing tool, and matrix equation solvers.
*   **Step-by-Step Breakdowns:** Many tools show the exact algorithmic, row-by-row, or derivative-by-derivative steps taken to reach a solution.
*   **Report Generation:** Built-in support for exporting interactive step-by-step solutions and graphs into clean PDF documents.

## 🛠️ Built With
*   **HTML5 & CSS3** (Custom layouts and CRT styling)
*   **Vanilla JavaScript** (Core logic and interactivity)
*   **Plotly.js** (Hardware-accelerated WebGL graphing)
*   **Math.js** (Symbolic math and parsing)
*   **html2pdf.js** (Document export)

## 🚀 Usage
Simply open the main hub page in any modern web browser. Select a semester from the dashboard to see the available programs, and click any active button to launch that specific tool. Use the back button in the top left corner of any tool to return to the semester dashboard.
